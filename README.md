# KT Neural Document Agent

HackAlem AI · TheDArk · Қазақтелеком тапсырмасына арналған AI Command Center интерфейсі. Kazakhtelecom стилінен шабыт алған хакатон концепті; ресми өнім емес.

## Мәселе және шешім

Қайта ұйымдастыру кезінде құжат редакцияларындағы функциялар жоғалуы, қайталануы немесе жауапкершілік өзгеруі мүмкін. Интерфейс екі редакцияны байланыстырады, өзгерістерді нейрондық картада көрсетеді және әр тұжырымнан құжаттың тармағына өтуге мүмкіндік береді.

Ортасында анимациялық Neural Core, екі жағында Document A/B, төменде Agent командалық жолы орналасқан. Чат тарихының орнына сұрақтың жауабы жеке Agent Insight терезесінде ашылады.

## Іске қосу — үш файл жеткілікті

`index.html`, `style.css`, `script.js` файлдарын **бір папкада** сақтаңыз. `index.html` файлын браузерде ашыңыз. Демо үшін орнату немесе API кілті қажет емес. VS Code ішінде Live Server арқылы да ашуға болады.

Репозиторийдегі жергілікті серверді Node.js 18+ арқылы іске қосу:

```sh
npm start
```

Нәтиже: **http://127.0.0.1:5173**. Браузер ескі көріністі сақтаса, Ctrl+Shift+R басыңыз. `npm run check` JavaScript синтаксисін тексереді. npm тәуелділіктері мен build қадамы жоқ.

## Демо жолы

1. «Демо іске қосу» → екі мысал модулі қосылады.
2. «INITIATE INTELLIGENCE» → алты tool кезеңі көрсетіледі.
3. Картада 14 өзгеріс пайда болады: +05 жаңа, −03 жоғалу қаупі, ↻04 өзгерген, ≈02 қайталану.
4. M1 түйінін басыңыз: 3.5-тармақтың екі редакциясы Source Trace ішінде қатар ашылады.
5. ASK THE AGENT жолына «ДИТААД туралы түсіндір» жазыңыз.
6. Ctrl+K / Cmd+K → команда таңдаңыз; ↑/↓ және Enter жұмыс істейді.
7. «Есеп» → JSON, CSV немесе PDF. PDF батырмасы басып шығару терезесін ашады: «PDF сақтау / Басып шығару» → браузерде «Save as PDF» таңдаңыз.

Қосымша: NEW / LOST / TRANSFORMED / OVERLAPS / SOURCE MAP сүзгілері; презентация режимі; анимацияны өшіру; мобильді көрініс; файлдарды сүйреп қосу; талдауды тоқтату және жаңа сессия.

## Демо мен нақты талдаудың айырмасы

Әдепкі `DEMO_MODE = true`. **Таңдалған файлдар оқылмайды және серверге жіберілмейді.** Кез келген жүктелген жұп үшін №8 → №9 алдын ала дайындалған сценарий көрсетіледі. Upload scanning, tool кезеңдері, 47 функция, 1 184 байланыс, 96% confidence және Document DNA — демонстрация. DNA ғылыми өлшем емес.

3.4, 3.5 және 5.3.2 тармақтарының үзінділері берілген DOCX файлдарымен тексерілген. «Тесттік» тұжырымдар мен «ДЕМО-…» тармақтары жасанды. Үзінділердің түрі Source Trace пен экспортта белгіленген. Құрылымдағы өзгеріс функцияның ресми ауысқанын өздігінен дәлелдемейді.

Интерфейс операциялар күйін көрсетеді; модельдің ішкі ойлау тізбегін көрсетпейді. Еркін сұрақтарға шынайы жауап және құжаттарды өңдеу команданың backend модулінде орындалуы керек.

## Архитектура және backend

```text
index.html  → экран құрылымы, диалогтар, қолжетімділік
style.css   → responsive Command Center, core/orbit/scan анимациялары
script.js   → Canvas, күй, демо, карта, Agent Insight, API, экспорт
                     │
                     ├─ DEMO_MODE=true  → жергілікті сценарий
                     └─ DEMO_MODE=false → Agent API
                          POST /api/documents
                          POST /api/analyze
                          POST /api/agent
                          GET  /api/session/:id
                          GET  /api/evidence/:id
```

Backend қосу үшін `script.js` басында `DEMO_MODE = false`, `API_BASE = 'http://127.0.0.1:8000'` орнатыңыз. Backend CORS пен файл валидациясын баптауы тиіс. `server.cjs` — тек статикалық сервер, Agent API емес. API келісімі: [docs/integration.md](docs/integration.md).

Қолдау: PDF, DOCX, XLSX; әр редакцияға бір файл, файл көлемі 20 MB-тан аспайды. Клиент кеңейтімді, көлемді және бос файлды тексереді. Мазмұнды backend тексеруі керек. Сұрауларда 120 секунд таймаут бар. Нақты режимде қате шықса, демо жауабына үнсіз ауыспайды. «Күтуді тоқтату» браузер сұрауын үзеді; сервер тапсырмасын жоюға кепіл емес.

API мәтіндері HTML ретінде орындалмайды. CSV формула префикстері қорғалған. API кілттерін frontend-ке салмаңыз. Сессия күйі жадта ғана сақталады; жаңартқанда жойылады. Нақты режимде Settings арқылы сервердің session_id мәнін енгізіп қалпына келтіруге болады. Google Fonts жүктелмесе жүйелік қаріптер қолданылады.
