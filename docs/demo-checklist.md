# Қабылдау тексеруі

- Startup 2–3 секундта жабылады, skip жұмыс істейді.
- Файл кеңейтімі/20 MB/бос файл тексеріледі; drag-and-drop жұмыс істейді.
- Екі құжатсыз талдау батырмасы өшірулі.
- Демо талдаудан кейін 14 node; сүзгілер саны 5 / 3 / 4 / 2.
- M1 Source Trace екі редакцияның 3.5-тармағын ашады.
- Демо жасанды тармақтары мен confidence белгіленген.
- ДИТААД сұрағы Agent Insight ашады және картадағы түйіндерді белгілейді.
- Ctrl/Cmd+K → іздеу → ↑/↓ → Enter; Escape диалогты жабады.
- JSON және CSV жүктеледі; PDF жаңа терезе арқылы басып шығарылады.
- Cancel және жаңа сессия ескі async нәтижені жаңа экранға енгізбейді.
- Мобильді экранда көлденең overflow жоқ; барлық басқару элементтері қолжетімді.
- Нақты режим: documents → analyze → agent; session restore және evidence сұраулары дұрыс endpoint-ке барады.
- API қатесі көрінеді; демоға автоматты ауысу жоқ.

Синтаксис: `npm run check`. Толық LLM сапасы мен DOCX/PDF/XLSX парсингі backend қосылған соң бөлек тексеріледі.
