# Нақты OpenAI backend-ті қосу

**Windows-та npm табылмаса:** жоба түбіндегі `start-agent.cmd` файлын екі рет басыңыз. Ол жоба папкасына өзі өтеді, Python-ды табады, алғашқы рет кітапханаларды орнатады және серверді іске қосады. Терезені ашық қалдырып, http://127.0.0.1:8000 ашыңыз.

Бұл API Neural Core интерфейсіне арналған. Бұрынғы `project/app.py` терминал бағдарламасы бөлек сақталған.

1. Жоба түбіндегі `.env.example` файлын `.env` деп көшіріңіз. `.env` ішіне **OpenAI API** кілтін енгізіңіз:

   ```env
   OPENAI_API_KEY=өз_кілтіңіз
   OPENAI_MODEL=gpt-4.1-mini
   ```

   Кілтті `script.js` ішіне немесе GitHub-қа салмаңыз. `project/dark.env` автоматты оқылмайды. Бұрын жарияланған кілт болса, жаңасын пайдаланыңыз. Басқа провайдердің кілті бұл backend-ке сәйкес келмейді.

2. VS Code → Terminal → New Terminal. `package.json` тұрған папкада:

   ```sh
   npm run agent:setup
   npm run agent
   ```

3. **http://127.0.0.1:8000** ашыңыз. Осы сервер интерфейсті нақты API режимінде береді. `script.js` ішіндегі DEMO_MODE мәнін қолмен өзгерту қажет емес. Екі құжатты таңдаңыз → INITIATE INTELLIGENCE.

`npm start` / 5173 және үш файлдық ZIP демо ретінде қалады. Команданың дайын backend-іне қосу үшін оның URL-ін `API_BASE` жолына, `DEMO_MODE = false` мәнін script.js басына орнатыңыз. Endpoint келісімі: `docs/integration.md`.

Күй: `/api/health` кілттің бар-жоғын ғана көрсетеді; шынайы жарамдылығын тек API сұрауы анықтайды. API сипаттамасы: `/api/docs`.

## Өңдеу

- DOCX абзацтары мен кестелері, мәтіндік PDF, XLSX жолдары оқылады. XLSX формулалары орындалмайды. Скан PDF үшін алдын ала OCR керек.
- Тармақ нөмірі мәтінде болса сақталады; болмаса абзац/бет/кесте/жол координатасы көрсетіледі. Word автоматты нөмірлеуі мен тақырып/колонтитул толық қалпына келтірілмейді.
- Әр файлға 20 MB; жалпы мәтінге 200 000 таңба; әр құжатқа 2 000 үзінді. Шектен асқанда мәтін үнсіз қысқартылмайды, қате қайтарылады.
- OpenAI дереккөз ID-лерін қайтарады. Backend ID-ді тексеріп, картаға үзіндіні бастапқы мәтіннен өзі қояды. Confidence/ұқсастық пайыздары ойдан шығарылмайды. Мәтіндік дәлелдің болуы семантикалық қорытындының дұрыстығына кепіл емес.
- Құжат мәтіні талдау/сұрақ кезінде OpenAI API-ға жіберіледі. `store=False` қолданылады; бұл провайдердің барлық сақтау саясатын алмастырмайды.
- Сессиялар RAM ішінде, белсенділік тоқтағаннан кейін 1 сағат сақталады; сервер өшкенде жойылады. Ең көбі 20 сессия. Бір worker қолданыңыз.
- Сервер localhost үшін, пайдаланушы авторизациясы жоқ. Интернетке тікелей жариялауға арналмаған.

OpenAI Responses API және Structured Outputs: https://developers.openai.com/api/docs/guides/structured-outputs

Бұл сессияда dependency орнатуға рұқсат берілмеді; сондықтан нақты OpenAI сұрауымен толық тексеру әлі орындалмады. Алдымен `npm run agent:setup` іске қосыңыз.
